4. About CPU Scheduling

Fundamental concepts, terminologies, and definitions for Diploma Computer Engineering students.

What is CPU Scheduling?

CPU Scheduling is the process by which the Operating System decides which process in the ready queue gets access to the CPU for execution, maximizing CPU utilization and system throughput.

Priority Scheduling

Each process is assigned a priority value. The CPU is allocated to the process with the highest priority (in our simulator, smaller priority number = higher priority). In non-preemptive mode, once running, it executes till completion.

Round Robin (RR)

A preemptive algorithm designed for time-sharing systems. Each process is given a small fixed slice of CPU time called a Time Quantum. If incomplete, it is moved to the back of the ready queue.

Preemptive vs Non-Preemptive

Preemptive: The OS can interrupt a running process before it finishes (e.g., Round Robin).
Non-Preemptive: Once a process starts CPU execution, it holds the CPU until it finishes or requests I/O.

Key Time Metrics

  • Arrival Time (AT): Time when process enters Ready Queue.
  • Burst Time (BT): CPU execution time required by the process.
  • Time Quantum (TQ): Fixed CPU time slice allotted per turn in Round Robin.

Formula Reference

  • Completion Time (CT): Time at which process finishes.
  • Turnaround Time (TAT): TAT = CT - AT
  • Waiting Time (WT): WT = TAT - BT
  • Response Time (RT): RT = First Start Time - AT

5. Algorithm Step-by-Step Execution Rules

Standard flow charts and logical procedures executed by the scheduling algorithms.

Non-Preemptive Priority Scheduling Steps

  1. Start: Initialize current time = 0 and mark all processes as incomplete.
  2. Read Input: Read Process ID, Arrival Time (AT), Burst Time (BT), and Priority.
  3. Check Arrived Processes: Identify all processes with AT ≤ Current Time that haven't executed.
  4. Select Highest Priority: Pick the process with the smallest priority number. If tie, select smallest AT.
  5. Execute Process: Run process completely for its full Burst Time (BT). Advance Current Time += BT.
  6. Compute Metrics: Calculate CT, TAT = CT - AT, WT = TAT - BT, and RT = First Start Time - AT.
  7. Check CPU Idle: If no process has arrived, advance time to next process AT.
  8. Repeat: Continue until all processes finish execution.
  9. Display Output: Render Gantt Chart timeline, calculation table, and averages.

Preemptive Round Robin Scheduling Steps

  1. Start: Initialize ready queue, current time = 0, and track remaining burst times.
  2. Read Input: Read Process ID, Arrival Time (AT), Burst Time (BT), and Time Quantum (TQ).
  3. Initialize Queue: Add all processes with AT = 0 into the ready queue.
  4. Dequeue Process: Take the first process from the front of the ready queue.
  5. Execute Time Quantum: Execute for min(Remaining BT, TQ). Advance current time.
  6. Enqueue New Arrivals: Add any processes that arrived during this time interval to the back of the ready queue.
  7. Re-queue / Finish: If process has remaining BT, push it to back of queue. Otherwise, set CT.
  8. Handle Idle CPU: If ready queue is empty and processes remain, advance time to next arrival.
  9. Calculate Results: Compute CT, TAT, WT, and RT for each process.
  10. Display Output: Render Round Robin Gantt Chart and summary statistics.
